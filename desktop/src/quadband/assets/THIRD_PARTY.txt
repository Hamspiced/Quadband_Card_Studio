A source-only checkout/archive installs dependencies separately and contains no vendor runtimes. PySide wheels include Qt modules and third-party components; preserve their bundled license files. ## Independent protocol implementations

Credit to **Tototo31 and Ashsh from the Dangerous Things community** for their work on the ACR122/ACR1552 scripts and reader-configuration research that informed the reader tools.

The Swift and Python implementations use documented commands and formats. The manufacturer's Piswords Windows executable/runtime and Chameleon firmware are **not** redistributed. The original project README lists ACS, NXP, MSR, NFC and Piswords references. T5577 open-write framing and independent encoders are documented in `docs/T5577.txt` with links to official Chameleon sources.

RF preset values are credited to **Tototo31 and Ashsh**: https://forum.dangerousthings.com/t/acr1552u-change-rf-power-level-duty-cycle/28545 . The user supplied an `acr1552u_rf_config.py` reference file with no explicit redistribution license found in the supplied file or linked discussion. That local reference is **excluded from public source archives and default builds**. It is not relicensed as Quadband code. Reader controls are independently implemented and continue to work without it; authors' permission would be required before adding that particular file to a public repository.
